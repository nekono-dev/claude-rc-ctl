# claude-rc-maint 要件定義書

## 1. 目的

版を固定して動く常駐サーバーを、claude 本体の更新後に新しい版へ切り替え、固定した実行ファイルが失われたサーバーを再起動し、使われなくなった版を削除する。起動ラッパーが前回の環境を再利用するため、再起動してもセッションは失われない。あわせて、起動に失敗したセッションと認証失敗で止まったセッションを検出して警告する。

## 2. スコープ

### 2.1 対象

- claude 本体が更新されたサーバーの検出と再起動。
- 固定した実行ファイルの消失の検出と、使われなくなった版の削除。
- セッションの起動失敗の検出と警告。
- 認証失敗で止まったセッションの検出と警告。
- 判定の定期的な自動実行と、旧名の定期実行の撤去。

### 2.2 対象外

- セッションのアーカイブ。
- 再起動後のセッションの再接続（起動ラッパーと remote-control 本体が行う）。
- セッションを開いている間だけ有効なリマインダーの検出。
- 起動に失敗したセッションの自動的な再実行。

## 3. 前提

- 前提: claude-rc-ctl — 常駐インスタンスの登録情報と、版を固定して前回の環境を再利用する起動を利用するため。

## 4. 機能要件

- FR-1: 実行ファイルがホストの現在の claude と異なるサーバーは、実行中の子プロセスかリマインダーを持つセッションがなければ再起動する。
- FR-2: 実行中の子プロセスかリマインダーを持つセッションがあれば再起動を見送って警告し、停止中か本体が更新されていないサーバーは再起動しない。
- FR-3: 固定した実行ファイルが削除されたサーバーは、警告し、実行中の子プロセスを持つセッションがなければ再起動する。
- FR-4: 一括判定では、どのプロセスも使っておらず、10分以上使われていない版の複製を削除する。
- FR-5: すべての登録済みインスタンスを一括で判定でき、1件の失敗でほかのインスタンスの処理を止めない。
- FR-6: 判定は10分ごとに自動実行され、その定期実行はインストーラが有効化して旧名のものを撤去し、削除で撤去する。
- FR-7: 確認のみを指定すると、何も再起動・削除せずに、判定結果と理由だけを表示する。
- FR-8: 画面出力の起動失敗の記録や、記録の最後が認証失敗のセッションがあれば、件数・最新の記録・対処を警告し、同じ記録は繰り返し警告しない。

## 5. 非機能要件

- NFR-1: 登録済みインスタンスが10件のとき、一括判定を5秒以内に終える。

## 6. 受け入れ条件

- AC-1 (FR-1): 本体が更新されたサーバーは、セッションがないときも、実行中でないセッションだけがあるときも再起動される。
- AC-2 (FR-5): 未登録の名前を指定すると、何も再起動せずに失敗する。
- AC-3 (FR-2): 本体が更新されたサーバーでも、実行中の子プロセスかリマインダーを持つセッションがあれば、警告が表示され再起動されない。
- AC-4 (FR-2): 停止中のインスタンスと、本体が更新されていないサーバーは、セッションの有無によらず再起動されない。
- AC-5 (FR-1): 固定した実行ファイルと元の場所の claude が異なるサーバーは再起動され、同じか元の場所が開けなければ再起動されない。
- AC-6 (FR-3): 固定した実行ファイルが削除されたサーバーは、警告され、実行中のセッションがなければ再起動され、あれば再起動されない。
- AC-7 (FR-4): 一括判定で使われていない古い版は削除され、使われている版と作られたばかりの版は残り、確認のみでは削除されない。
- AC-8 (FR-5): 一括判定を指示すると、条件を満たす複数のインスタンスが再起動され、満たさないものは飛ばされる。
- AC-9 (FR-6): インストーラを実行すると、定期実行のユニットが配置されて有効化され、旧名のユニットは無効化されて撤去される。
- AC-10 (FR-6): 削除を指示すると、定期実行のユニットが無効化されて撤去される。
- AC-11 (FR-7): 確認のみを指定すると、対象と理由が表示され、サーバーは再起動されない。
- AC-12 (FR-8): サーバーの画面出力にセッションの起動失敗の記録があると、警告と対処が表示され、サーバーは再起動されない。
- AC-13 (FR-8): 警告済みの起動失敗は次回の判定で繰り返し警告されず、新しい失敗とサーバーの再起動後の失敗は警告される。
- AC-14 (FR-8): セッションの記録の最後が認証失敗だと警告と対処が表示され、回復したセッション・起動前の記録・別のディレクトリの記録は警告されない。
- AC-15 (FR-8): 警告済みの認証失敗は次回の判定で繰り返し警告されず、新しい失敗は警告され、確認のみでは記録されない。
- AC-16 (NFR-1): 登録済みインスタンスが10件のとき、一括判定が5秒以内に終わる。
